# Glass screen stills

Regenerated by `spinme/host/test_screenshots` (from `spinme/host`:
`make build/test_screenshots && ./build/test_screenshots`).

Uses the **device** `glyphs.bin` and `disintegration_360.rgba`, same layout
constants as `ta_glass_device.cpp`. Panel is 360x360; PNGs are written at
3x (1080x1080) nearest-neighbor for readable review.

| File | Screen |
|------|--------|
| `main_mpd.png` | Main / default quiet glass (`spinme` + clock) |
| `main_playing.png` | Main with sample artist/album/title + playing |
| `selecting_overlay.png` | Selecting mode (down arrow + 100x100 ring) |
| `kv_view.png` | KV page still |
| `kv_edit.png` | KV edit still |
